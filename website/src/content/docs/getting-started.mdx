gocontainer holds your app's services, each under a key that fixes its type. It has two types:

- **Key[T]** names a service of type `T`. Its methods put the service in a container and get it out as a `T`.
- **Container** holds the services. The zero value is empty and ready to use.

## Install

gocontainer needs Go 1.26 or newer.

```sh
go get github.com/vardius/gocontainer/v2
```

## Run it

<Steps>

1. From a clone of the repository:

   ```sh
   go run ./examples/wiring
   ```

2. It greets the two users it knows and logs a warning for the one it doesn't:

   ```txt
   Hello, Ada.
   Hello, Grace.
   time=… level=WARN msg="unknown user" id=3
   Hello, stranger.
   ```

</Steps>

## What just happened

- Each key, made with `NewKey`, named a service and fixed its type: `usersKey` is a `Key[Users]`.
- `usersKey.Register` took a `memoryUsers`, which implements `Users`, with no conversion. A value that isn't a
  `Users` wouldn't have compiled.
- The greeter was built from services registered before it, with `MustGet`, which returns the key's type:
  no type assertions anywhere.
- `main` declared the container. There is no global one, and nothing ran in `init()`.
