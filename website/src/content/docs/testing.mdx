A key works with any number of containers, and finds in each the service registered there. So code that takes
its services from a container can be tested with fakes: register them under the same keys, in a container the
test makes for itself.

```go
var c gocontainer.Container
Users.Register(&c, downUsers{}) // a fake whose every call fails

h := routes(&c) // built with the fake
```

Each test gets a fresh container, so tests don't see each other's fakes and can run in parallel. There is no
global container to reset.

## Fakes need interface keys

A fake can only go in under a key whose type it fits. Give the services you'll fake an interface key, such as
`Key[Users]`; a key for a concrete type, such as `Key[*SQLUsers]`, only takes that type.
